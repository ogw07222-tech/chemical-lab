# Architecture Decision Records

Use this directory for decisions that materially change cross-system behavior or long-term architecture.

Recommended filename: `ADR-0001-short-title.md`

Each ADR should state:
- Context
- Decision
- Alternatives considered
- Scientific implications
- Performance implications
- Compatibility/migration impact
- Status: PROPOSED / ACCEPTED / SUPERSEDED

Workstream 00 owns acceptance of cross-system ADRs.
